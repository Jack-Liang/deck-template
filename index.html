Part One

版式
组件

内容页的正文不是自由排版，而是往「版式槽」里填：卡片、数字、时间线、路径图、标签、金句、链接卡、代码、双栏、整页截图。这章各来一遍。

章节页：h2 的 span 换强调色；一段导语说明这章讲什么。

版式组件 · 数字

stats：三个大数字

数字比形容词有说服力。三块瓷砖各配一行小字，颜色自动按强调色—过渡色—深色递进。

0 运行时依赖：没有框架、没有构建
3 种导出：分发包 zip、打印 PDF、单文件 HTML
16:9 设计稿尺寸 1280×720，投影不满屏不变形
takeaway 是压轴

每页最底下那根深色结论条就是它——这句通常是你希望观众唯一记住的话，所以留到最后按 → 再亮（本页正在演示 fragment 步进）。

数字页：任何块加 class="fragment" 就能按 → 逐个亮起，不限于卡片；打印和导出 PDF 时全部自动展开成完整版。

版式组件 · 卡片

facts：三栏事实

不放数字的并列事实用 facts：三栏各一段，顶线条纹按强调色轮换。HTML 里的 init 类还能把缩写逐字母点亮，像这四个字母。

卡片 · facts / steps

并列的事实、流程、对照都走卡片；两栏放不下就三栏，六张卡自动排两行。

大图 · shot-inline / screen

截图嵌在文字旁用 shot-inline，整页只放一张图用 screen——录屏 GIF 也走这两个槽。

代码 · pre[data-lines]

代码块自带语法高亮，data-lines 声明步进分组，按 → 逐段点亮、未点到的行压暗不隐藏。

组合而非排版

标题区 + 一个正文槽 + 可选的 takeaway，就是一张内容页的全部结构；你决定往槽里放什么。

卡片页：facts 顶条颜色按 1/2/3 栏轮换（红-紫-蓝）；导语里的 init 首字母高亮适合展开缩写词。

版式组件 · 时间线

timeline：一条沿革

历史、路线图、演进史放这：竖轴自动渐变，圆点颜色按条目轮换，第三列是自由正文。

origin 原版引擎

larshp 为 DSAG 2026 场次写的纯 HTML 幻灯片，无框架无构建。

fork 类名通用化

把演讲专属的样式改写成设计系统：版式、组件、状态三层的通用类名。

you 你的场次

从这页开始往后都是你的内容——时间线最多三格，多了就拆两页。

时间线：第一列是装饰圆点（i 留空），第二列短标签，第三列标题+正文；条目数建议 2–3 条。

版式组件 · 标签

pills：一口气列完

不想逐条展开、又想让人看见全貌的时候：一行标签墙，放得下就自动换行。

无构建 零依赖 离线放映 16:9 适配投影 触屏翻页 总览模式 演讲者视图 逐段代码步进 深色页打印保真 单文件导出 zip 分发
标签墙：pills 里只有 span，没有图标和链接——它是「一览」不是「导航」，导航链接用 cards。

版式组件 · 金句

quote：一句话占一页

slide-sparse 修饰符去掉正文槽，让一句话独占整页。

工具越简单，讲的人越自由——模板的全部野心，是让你忘掉模板。 deck-template
金句页：section 上加 slide-sparse，quote 会自动放大；cite 是出处，可删。

版式组件 · 代码

data-lines：代码逐段讲

pre 上声明 data-lines="1,2-3,5"（1 基行号，逗号分步、支持区间），按 → 逐段点亮，未点到的行压暗不隐藏，代码块形状不变。

# 三条命令跑起来
python3 -m http.server 8644

# 浏览器打开（或者直接双击 index.html）
open http://127.0.0.1:8644
语法高亮内置

js/highlight.js 自带 bash / json / yaml / diff 语法，几十行、无依赖；代码页建议一页不超过十行，多了拆两页。

代码页：这页分四步点亮（第 1、2、3、5-6 行）；高亮语法表在 js/highlight.js 顶部的 GRAMMARS 里，加新语言就是加一条正则。

版式组件 · 双栏

split-body：左图右证

左边讲机制（mech 节点图），右边放证据（shot-inline 内嵌截图），下面压一根结论条。

内容 index.html + css/custom.css
↓  交给  ↓
引擎 js/deck.js + js/highlight.js
改内容不碰引擎

内容和引擎物理隔离：讲稿全在 index.html，行为全在 js/——你几乎永远只改前两个文件。

双栏页：mech 上下两个节点卡中间夹一行箭头；右栏 shot-inline 高度上限比整页版低，给 takeaway 留空间。

版式组件 · 大图

screen：图就是页

需要观众看清每个像素的那张图，整页给它：标题只留一行，图片吃掉剩下的全部高度，保持约 16:9 永远高度受限不溢出。

整页截图：录屏 GIF 放这个版式自动循环；相邻页的大图引擎会预热解码，首次翻到不卡帧。
过场页：一个词 + 一个装饰就够（「Demo?」「休息」「谢谢」）；太阳 SVG 是示例装饰，整个可换。
